These fixtures test the libraries of the ISMS home (ismsa/templates/moduleHome2): where planned evidence is created, the evidence links of the library controls, the NIS2 requirements and their planned controls, and the installation of the libraries.

* Test home L1 has the core and all four libraries. Its access rights review is passed, its review of the risk register is a draft, the training control has an overridden assessment, and the business continuity control is out of scope.
* Test home L2 has the core without the incident register, and the NIS2 library only.
* Test home L3 is an old-style home with a compliance register and no central control register. The NIS2 library must not be offered there.

The executable assertions are in tests/home-libraries.lp. Run this command in the root of the repository:

----
cyberismo calc run tests/home-libraries.lp
----

The test passes when "results" is empty and "error" is null.

Information systems support the primary assets. In addition to the fields that all assets have, such as the owner and the criticality, define these properties for each information system:

* the access control, for example the accounts, the access from public networks, and multi-factor authentication
* the responsibility for security updates
* the backups
* the level of logging and monitoring.

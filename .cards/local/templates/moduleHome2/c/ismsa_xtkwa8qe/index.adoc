== Libraries

Libraries add content to the home. Install only the libraries that the organisation needs:

[cols="3,4"]
|===
| Question | Library

| Do we need a full information security management system, for example for ISO/IEC 27001 or NIS2?
| Information security management, and asset and risk management

| Do we need to manage the risks of our own assets, also without a full management system?
| Asset and risk management

| Do we run IT or cloud services ourselves?
| Security operations, in the central control register

| Does NIS2 apply to us?
| NIS2, in the compliance register. NIS2 also needs the other libraries above

| Do we only need the central controls for our products, for example for the EU Cyber Resilience Act?
| No library. The core of the home is enough
|===

When a library is available for this home, a button to install it is shown here or in the register that the library extends.

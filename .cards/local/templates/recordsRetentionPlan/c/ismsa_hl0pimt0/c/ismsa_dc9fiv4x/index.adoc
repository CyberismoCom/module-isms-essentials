== Task description

Review the records retention plan.

[NOTE]
.Review instructions
====
* Check that the plan covers the regulations in the compliance register.
* Check that each type of record has an owner and a retention period.
* Check that a sample of the records exists and can be read.
====

To review the document, set the reviewer in the *Owner* field of this card. If the document is ready to be approved, transition this task to *Closed as done*. If the document needs changes, transition this task to *Changes required*.

NOTE: The reviewer cannot be the same person as the owner or the approver of the document.
